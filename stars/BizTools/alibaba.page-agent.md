# page-agent

JavaScript in-page GUI agent. Control web interfaces with natural language.


## ✦ 人工摘要

阿里的页面内嵌 GUI Agent（2.8 万 star，MIT，活跃）。一行 script 把 AI 代理嵌入网页，自然语言操控界面（点击/填表），纯文本 DOM 操作——不需要浏览器插件、无头浏览器或多模态模型。提供 MCP Server（beta）。

**对你（爬虫 + 独立站）的价值：网页自动化的新范式参考。** 传统爬虫是"写死选择器/无头浏览器"，page-agent 是"自然语言指挥 DOM"——复杂交互页面的自动化盲区它可能补上。独立站场景：产品页 AI 助手、表单自动填充可直接用。与你的 Python 爬虫主力是平行补充关系，不是替代。
