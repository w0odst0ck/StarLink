# aisuite

Simple, unified interface to multiple Generative AI providers 


## ✦ 人工摘要

吴恩达出品的轻量多 LLM 统一接口库（1.6 万 star，MIT，活跃）：一个 API 切换 OpenAI/Anthropic/Google/DeepSeek 等，带 Agents API（工具/工具包/MCP）。

**对你（多模型接入）的定位：项目内多模型切换的轻量库。** 与 OmniRoute（外部网关服务）定位不同——aisuite 是集成进代码的库。信息采集/舆情管线里不同任务用不同模型时，一行切换。Agents API 可与 pi（TS 系）对照研究。
